# Lorin AI Benchmark Evaluation Artifacts
Contains execution logs, diagnostic traces, failure taxonomy records, and ablation summaries for the Lorin AI RAG pipeline.

- `results_20261003_143314.json`: Full aggregate metrics and category breakdown.
- `results_20261003_143314.jsonl`: Complete query-by-query evaluation results.
- `failures_20261003_143314.jsonl`: Machine-readable audit file of all failed queries.
- `query_trace_20261003_143314.jsonl`: Retrieval diagnostic trace for every query.
- `summary_20261003_143314.md`: Executive summary markdown report.
- `leaderboard.csv`: Retrieval ablation benchmark leaderboard.
- `manual_review.md`: Top 25 failure cases for manual inspection.
- `regression_baseline.json`: Frozen baseline benchmark metrics.
