## 📚 Curriculum Details

The IT department follows **two regulations**:
- **2021 Regulation**
- **2017 Regulation**

### Key Subjects (2021 Regulation) include:
- Problem Solving and Python Programming
- Programming in C
- Data Structures and Algorithms
- Object Oriented Programming
- Artificial Intelligence and Machine Learning
- Database Management System
- Computer Networks
- Full Stack Web Development
- Web Essentials
- Embedded System and IoT

### Electives:
- **Open Electives**: Big Data Analytics
- **Professional Electives**: Software Testing and Automation, Data Warehousing

## 🎓 Programme Overview
- **Degree**: B.Tech. Information Technology
- **Duration**: 4 years (8 semesters) | 3 years for lateral entry (6 semesters)
- **Intake**: 60 seats (30 government quota + 30 management quota)
